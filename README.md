💧 Aquafina Homepage Clone

A desktop-focused UI clone of the Aquafina homepage built using pure HTML5 and CSS3.
This project was created to practice front-end layout structuring, styling, and visual accuracy by replicating a real-world brand website.


📌 Project Overview

This project recreates the visual layout of the Aquafina homepage using semantic HTML and structured CSS styling.

The primary goal was to strengthen core front-end fundamentals such as:

Page structure and semantic markup

Layout alignment and spacing

Typography and visual hierarchy

Background images and overlay content

Button styling and hover effects

⚠️ Note: This is a desktop-only implementation and does not include media queries or responsive behavior.


🛠️ Technologies Used

HTML5

CSS3

Visual Studio Code


🎯 Learning Objectives

Translating an existing website design into structured HTML

Implementing layout techniques using CSS

Improving spacing, alignment, and UI consistency

Understanding how brand websites organize visual sections
